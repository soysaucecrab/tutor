# Tutor — 과외 자료 (Typst)

> 📘 이 저장소는 Typst(`.typ`) 기반의 과외/학습 자료 모음입니다.  
> 주로 수학/물리 예제와 학습 템플릿이 포함되어 있습니다.  [oai_citation:0‡GitHub](https://github.com/soysaucecrab/tutor)

---

## 🧠 개요

이 프로젝트는 **Typst**를 활용해 과외/강의 자료를 작성하기 위한 예제 모음 및 템플릿입니다.  
Typst는 현대적이고 직관적인 조판 문법을 가진 오픈소스 문서 툴로서, 학습 자료/레포트/프린트물을 빠르게 작성할 수 있습니다.

## 🚀 시작하기

### ⚙️ Typst 설치

로컬에서 Typst을 설치해야 `.typ` 문서를 컴파일할 수 있습니다.

**macOS (Homebrew)**

```bash
brew install typst
```
**Linux
```bash
sudo apt install typst
```
**Windows (winget)
```bash
winget install --id Typst.Typst
```

📌 참고
	-	Typst는 수식, 표, 문단, 그림 등을 직관적으로 조판할 수 있습니다.
	-	이 저장소는 과외/수업자료 제작용으로 자유롭게 사용 가능합니다.
  - 다만, 꼭 저작권 표기를 하셔야 합니다.
